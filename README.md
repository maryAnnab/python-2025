# Python-Engineering 2025


> Engineering coursework projects focused on Python programming, algorithms and data structures

## Overview
Collection of practical Python programming projects completed during Computer Science degree program at WSIZ Bielsko-Biała (2024/2025). Projects cover core programming concepts, algorithms, data structures, web development, machine learning, and software engineering practices.

## Tech Stack
- **Languages:** Python 3.12
- **Package Management:** Poetry, conda, virtualenv
- **Development Tools:** PyCharm, Jupyter
- **Testing:** pytest, unittest, doctest, tox
- **Data Formats:** json, csv, yaml, datetime
- **Data Science:** NumPy, pandas, matplotlib, seaborn, SciPy, NetworkX
- **Web Frameworks:** Flask, Django, FastAPI
- **Machine Learning:** scikit-learn, TensorFlow, PyTorch, Keras
- **Databases:** sqlite3, psycopg2
- **GUI Development:** tkinter, Kivy
- **DevOps:** Docker, Kubernetes, Ansible, Jenkins, CI/CD
- **Cloud Services:** AWS SDK, Azure SDK
- **Security:** cryptography, secrets, ssl
- **Build Tools:** setuptools

## Key Topics Covered
- Python fundamentals and OOP principles
- Algorithm design and analysis
- Data structures implementation
- Web application development
- Machine learning and AI integration
- Database integration and ORM
- GUI application development
- DevOps and containerization
- Cloud deployment and automation
- Security and cryptography
- Testing and code quality

Each project includes:
